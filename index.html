Erros por cliente

Cada cartão é um cliente. Erros iguais são agrupados (números e ids são ignorados na comparação); um erro resolvido volta a abrir se acontecer de novo. Falhas de entrega do WhatsApp também entram aqui.

Teste automático de conversas

Roda no "Negócio de Teste (QA)", isolado e em modo simulação: nenhuma mensagem real é enviada. Usa a IA padrão da plataforma de verdade, então cada lote consome alguns tokens.

Segmentos

Um segmento é o modelo de um ramo de negócio. Textos (nomes, instruções, regras e perguntas) valem na hora para todos os clientes do segmento. Padrões (serviços, preços, horários e regras de agenda) só preenchem clientes novos. Para um ramo novo, duplique o Genérico.

Termo de uso

Um modelo único para todos os clientes. Os campos entre {{ }} são preenchidos com os dados de cada cliente na aba Contrato dele. Mudar o modelo vale para os próximos termos impressos; os já emitidos ficam guardados como foram.
